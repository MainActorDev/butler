The authoring flow (live-proven: glm-5.3-flash, condition 3)

1. user message → conversation API (or MCP tools/call — same registry) 2. session resumed from rows alone (butler_messages replay) 3. loop assembles context → provider call (budgets: wall clock owns everything) 4. model asks docs.search → BM25 over ingested chunks → top-k observations 5. model asks docs.get → full ticket fixture by sha256 (provenance: it cites hashes) 6. model calls spec.draft → validator: INVALID external signal, not self-critique 7. model repairs draft → validator: INVALID (observed twice in the live drill) 8. model repairs again → validator: VALID ✓ 9. act-class tools? refused by policy (DRAFT) — human presses publish 10. final answer + cited sha256 → persisted; turn events stream over WS; per-turn tokens accounted every message, tool call, and token lands in butler_messages — the session is replayable from rows alone
